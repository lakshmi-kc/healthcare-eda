# 🏥 Healthcare EDA

Exploratory Data Analysis on a healthcare dataset to study patient health patterns and medical trends.

---

## 📌 Project Overview

This project performs in-depth EDA on a healthcare dataset containing patient information such as age, gender, medical conditions, and health indicators. The analysis uncovers health patterns and trends across different patient groups.

---

## 📂 Dataset Features

| Feature | Description |
|---------|-------------|
| `age` | Patient age |
| `gender` | Patient gender |
| `medical_condition` | Diagnosed condition |
| `admission_type` | Type of hospital admission |
| `medication` | Prescribed medication |
| `test_results` | Medical test results |
| `billing_amount` | Hospital billing amount |

---

## 🛠️ Tools & Libraries

- **Data Processing:** Pandas, NumPy
- **Visualization:** Matplotlib, Seaborn
- **Analysis:** Statistical EDA techniques

---

## 🔍 Project Workflow

1. Data Loading and Overview
2. Data Cleaning — handling nulls and duplicates
3. Univariate Analysis — distribution of individual features
4. Bivariate Analysis — relationships between features
5. Age and Gender Analysis — health trends by demographics
6. Medical Condition Analysis — most common conditions
7. Billing Analysis — cost patterns across conditions
